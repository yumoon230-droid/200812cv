# 문여울 웹 이력서

GitHub Pages에 바로 게시할 수 있는 정적 웹사이트입니다. 별도의 설치나 빌드가 필요하지 않습니다.

## 게시 전 수정

`index.html`을 메모장이나 코드 편집기로 열고 `your-email@example.com`을 실제 공개용 이메일로 바꾸세요. 공개 저장소이므로 상세 주소, 생년월일, 개인 휴대전화는 넣지 않는 것을 권장합니다.

사이트 내용은 제공된 `이력서_문여울.docx`의 학력, 경력, 자격, 자기소개 내용을 바탕으로 공개용 문장으로 정리했습니다.

## GitHub Pages 게시 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 압축을 푼 뒤 이 폴더 안의 모든 파일과 `assets` 폴더를 저장소 최상단에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다.
6. 잠시 후 표시되는 웹 주소로 접속합니다.

## 파일 구성

- `index.html` — 이력서 내용
- `style.css` — 디자인과 모바일·인쇄 스타일
- `script.js` — 연도 자동 표시
- `assets/profile.jpg` — 프로필 사진
- `.nojekyll` — GitHub Pages용 설정

웹페이지의 **PDF 저장** 버튼을 누르면 브라우저 인쇄 기능으로 PDF 이력서를 만들 수 있습니다.
